Painel do site

Área restrita. Para editar fotos e textos é preciso a chave de acesso do GitHub do dono do site.

Como criar a chave (uma vez só):
  1. Entre no GitHub, clique na sua foto, depois em Settings.
  2. Na lateral, vá no final em Developer settings, depois Personal access tokens, depois Fine-grained tokens e Generate new token.
  3. Dê um nome, escolha a validade, em Repository access marque Only select repositories e escolha o repositório do site.
  4. Em Permissions, Repository permissions, coloque Contents como Read and write.
  5. Clique em Generate token e cole a chave aqui. Ela só é mostrada uma vez, não compartilhe com ninguém.
